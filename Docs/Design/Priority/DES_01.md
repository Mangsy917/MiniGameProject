## 플레이 방법

위에서 내려다본 미로에서 캐릭터를 드래그해, 창이 튀어나오는 바닥과 특정 구간을 왕복하는 적을 피해 출구까지 가라. 창에 찔리거나 적에 닿으면 실패.

## 성공 / 실패

- **성공**: 캐릭터가 출구에 닿으면 즉시 성공.
- **실패**: 창이 나온 바닥을 밟거나, 적에 닿거나, 시간 안에 출구에 도착하지 못하면 실패.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 함정 바닥 수 | 3 | 통로마다 1개. 프리팹에 직접 배치 (`Trap IMGs`) |
| 창 주기(초) (`Trap Period`) | 1.6 | 함정마다 시작 시점 랜덤 |
| 창이 나와 있는 비율 (`Spear Ratio`) | 30% | - |
| 적 수 (`Patrols`) | 2 | 두 번째·세 번째 통로에서 좌우 왕복, 시작 위치 랜덤 |
| 적 속도 | 260 | - |
| 캐릭터 속도 (`Move Speed`) | 900 | 손가락 위치를 일정 속도로 따라감. 벽은 통과하지 못함 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
