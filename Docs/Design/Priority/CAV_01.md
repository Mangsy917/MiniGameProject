## 플레이 방법

화면 정중앙의 장작 위에서, 고정된 부싯돌에 손에 든 부싯돌을 위아래로 여러 번 비벼 불을 붙여라. 너무 빨리 비비면 부싯돌이 부서져 실패.

## 성공 / 실패

- **성공**: 정해진 횟수만큼 비비면 불이 붙어 성공.
- **실패**: 너무 빨리 비비면 부서져 실패. 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 비비기 횟수 (`Min/Max Strikes`) | 6~10 | 매번 랜덤. 위로 1회, 아래로 1회를 각각 셈 |
| 한 번으로 인정하는 거리 (`Min Stroke`) | 120 | - |
| 움직일 수 있는 거리 (`Move Range`) | 위아래 100 | - |
| 최대 속도 (`Fastest Screen Time`) | 화면 높이/0.12초 | 이보다 빠르면 실패 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
