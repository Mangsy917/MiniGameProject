# DES_04 벽화의 틀린 부분을 찾아라 — 에셋 자리 (우선제작)

아트팀이 이 폴더에 아래 파일을 넣는다. 파일이 없는 동안 코드는 임시 이미지를 쓴다.

- 지시문: 찾아라!
- 플레이 방법: 왼쪽 원본 벽화와 비교해서 오른쪽 벽화의 틀린 부분 1곳을 탭해라. 탭한 자리에 빨간 원이 생기고, 원 안에 틀린 부분이 겹치면 성공.
