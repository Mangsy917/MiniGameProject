## 공통 규칙

- **게이지바**: 아래쪽 게이지를 채우는 방식의 미니게임에는 게이지바를 두지 않는다. DES_15의 게이지는 남은 선 길이라서 예외.
- **랜덤 수치**: 맞춰야 하는 값은 매번 랜덤이다. 돌리기(DES_10, JUN_08, FOR_19), 발굴(CAV_08, PRE_03), 초점(PRE_02, LAB_08), 카드 긁기(LAB_01), 부싯돌(CAV_01), 초크 털기(PRE_16). FOR_14의 젓는 속도는 고정.
- **속도 증가**: DES_03, CAV_09, JUN_04, JUN_09, FOR_01은 제한시간이 5초보다 짧아질수록 빨라진다 (1초당 +50%, `Speed Up Per Second`).
- **놀이 영역**: 800 × 500. 화면 비율이 달라도 통째로 축소해서 보여 준다 (화면 방향 미정).

## 확인 필요 모음

- **CAV_09**: 돌 속도를 올린 뒤 4초 제한에서 자동 테스트가 3번 중 2번 실패했다. 난이도 확인 필요.
- **DES_01**: 4초 제한에서 자동 테스트로 2.3~3.7초가 걸린다. 난이도 확인 필요.
- **CAV_08, PRE_03**: 목표 횟수가 12이면 4초 제한에서 빠듯하다.
- **LAB_19**: 20탭은 4초 제한에서 초당 5번이다.
- **DES_15, DES_01**: 박쥐와 적은 제한시간에 따라 빨라지지 않는다. 함께 빨라지게 할지 확인 필요.
- **LAB_19**: 이름은 '타자기'지만 화면은 컴퓨터 문서 프로그램이다. 이름을 바꿀지 확인 필요.
- **PRE_16**: 지시문 '털어라!'는 임의로 정했다.
- **전체**: 실제 휴대폰에서 아직 확인하지 않았다.
