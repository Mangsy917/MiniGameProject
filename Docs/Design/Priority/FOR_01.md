## 플레이 방법

비스듬히 내려다본 화면 가운데의 못을 연타해서 박아라. 한 개를 다 박으면 옆으로 넘어가 다음 못이 나온다. 못은 총 4개이고, 다음 못으로 완전히 넘어가야 박을 수 있다.

## 성공 / 실패

- **성공**: 못 4개를 모두 박으면 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 못 수 (`Nail Count`) | 4 | - |
| 못 하나당 탭 수 (`Taps Per Nail`) | 3 | - |
| 넘어가는 속도 (`Slide Speed`) | 3200 | - |
| 빨라지는 정도 (`Speed Up Per Second`) | 0.5 | 제한시간이 5초보다 1초 짧아질 때마다 +50% (4.5초 1.25배, 4초 1.5배) |

거리와 속도는 놀이 영역(800 × 500) 단위다.
