## 플레이 방법

오른쪽의 낚싯대 릴을 돌려서 물고기를 위로 끌어올려라. 멈추면 다시 내려간다.

## 성공 / 실패

- **성공**: 릴을 다 감으면 물고기를 낚아 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 필요 회전 수 (`Min/Max Turns`) | 2.5~4바퀴 | 매번 랜덤 |
| 되감기 속도 | 초당 15% | - |
| 물고기 이동 (`Fish Move`) | (15, 140) | 낚싯대 끝을 향해 위로 |
| 멀리 있을 때 크기 (`Far Scale`) | 0.5 | 끌려올수록 커짐 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
