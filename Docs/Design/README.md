## 미니게임 ID 규칙

`{테마 코드}_{번호}` — 번호는 시트의 테마 안 순서(01~20).

| 테마 | 영문 (폴더·씬 이름) | 코드 |
|---|---|---|
| 사막 | Desert | DES |
| 정글 | Jungle | JUN |
| 동굴 | Cave | CAV |
| 절벽 | Precipice | PRE |
| 숲 | Forest | FOR |
| 연구소 | Laboratory | LAB |

## 문서 갱신 방법

구글 시트를 고친 뒤 이 폴더의 `minigames.json`, `minigames.csv`, `MiniGames/*.md`를 다시 만든다. ID는 시트의 행 순서로 매겨지므로, **시트에서 행 순서를 바꾸면 ID가 바뀐다.** 이미 구현된 미니게임이 있으면 행 순서는 바꾸지 않는다.
