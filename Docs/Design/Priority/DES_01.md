# DES_01 피라미드의 함정을 피해라

> 우선제작 미니게임. 이 문서만 보고 구현할 수 있게 정리했다. 원본은 구글 시트 '우선제작 미니게임' 탭.

## 기본 정보

| 항목 | 값 |
|---|---|
| ID | `DES_01` |
| 테마 | 사막 (Desert) |
| 지시문 (`Title`) | 피해라! |
| 끝나는 조건 | 버티기 → `SucceedOnTimeUp = true` |
| 플레이 방식 | F 스와이프, G 드래그 |
| 공통 템플릿 | 장애물 피하기 — 캐릭터를 움직여 장애물과 닿지 않게 함. |

## 플레이 방법 (시트 원문)

캐릭터를 드래그해서 창이 튀어나오는 바닥을 피해 출구까지 가라. 창에 찔리면 실패. (참고: 감옥탈출)

## 성공 / 실패

- **성공**: 캐릭터가 출구에 닿으면 즉시 성공 (`Finish(true)`).
- **실패**: 창이 튀어나온 바닥 위에 있으면 즉시 실패.
- 제한시간은 `StageFlowController`가 잰다 (5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (인스펙터에 노출, 아래 값이 기본값)

| 수치 | 기본값 | 설명 |
|---|---|---|
| 함정 바닥 칸 수 | 6 | 출구까지 경로 위에 배치 |
| 창 주기(초) | 1.0 | 튀어나왔다 들어가는 반복 주기, 칸마다 시작 시점 다르게 |
| 캐릭터 이동 방식 | 손가락 위치 따라가기 | 드래그한 위치로 바로 이동하지 않고 일정 속도로 따라감 |

## 확인 필요 (기획자 답변 전까지 아래 가정으로 구현)

- [ ] 끝나는 조건이 '버티기'인데 플레이 방법은 '출구까지 가라'입니다. 출구에 닿으면 바로 성공으로 처리하고, 시간이 끝날 때까지 출구에 못 가도 찔리지 않았으면 성공(버티기)으로 둘지 확인 필요. 이 문서는 둘 다 성공으로 적음 (`SucceedOnTimeUp = true` + 출구 도착 시 `Finish(true)`).

## 완료 체크

- [ ] 조정 수치가 인스펙터에 있다
