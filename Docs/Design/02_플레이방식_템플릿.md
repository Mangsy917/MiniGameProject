# 플레이 방식과 공통 템플릿

## 플레이 방식 기호

| 기호 | 이름 | 정의 | 사용 수 |
|---|---|---|---|
| A | 연타 | 탭을 N번 반복 | 20 |
| B | 좌우 회피 | 좌·중·우 3칸 중 하나를 골라 옮기는 방식 (참참참) | 2 |
| C | 대상 탭 | 화면의 대상을 탭. 정답만 탭하고 오답을 탭하면 실패하는 형태 포함 | 30 |
| D | 타이밍 탭 | 대상이 구역에 들어올 때 탭 | 4 |
| E | 홀드 | 누르고 있기 / 떼기 | 4 |
| F | 스와이프 | **좌우로만** 드래그 | 18 |
| G | 드래그 | **X·Y축 자유 이동**. 끌어다 놓기, 문지르기, 슬라이더, 선 잇기, 회전(손잡이 돌리기) 포함 | 43 |
| H | 틀린그림 찾기 | 두 그림을 비교해 다른 곳 탭 | 4 |
| I | 순서대로 누르기 | 화면에 보이는 순서(번호·그림·크기·색)대로 탭 | 10 |
| J | 터치X | 화면을 건드리지 않고 버티기 | 1 |

한 미니게임에 기호가 2개 이상이면 조작을 섞은 것이다 (예: `G 드래그, C 대상 탭`).
시트의 `B 좌우 터치`(JUN_07)는 `B 좌우 회피`와 같은 뜻이다.

## 공통 템플릿 (구현 권장)

미니게임 대부분은 아래 템플릿 중 하나에 그림과 수치만 바꿔 넣으면 된다. 템플릿을 먼저 만들고, 각 미니게임은 템플릿을 상속하거나 설정만 다르게 한 프리팹으로 만든다.

| 템플릿 | 설명 | 주요 설정값 | 대표 미니게임 |
|---|---|---|---|
| 정답 탭 | 대상 N개를 모두 탭하면 성공. 오답 대상을 탭하면 실패 (오답은 없을 수도 있음) | 정답 수, 오답 수, 배치 랜덤 여부 | DES_03 전갈, JUN_14 보트 구멍, CAV_15 횃불, FOR_11 사과, LAB_13 비커 |
| 하나 고르기 | 보기 중 정답 하나를 탭 | 보기 수, 정답 판정 데이터 | DES_13 동물 수, JUN_09 과일 수, FOR_04 발자국, LAB_12 선 찾기, PRE_18 헬멧 |
| 끌어다 놓기 | 물건을 맞는 자리(슬롯)로 드래그. 틀린 슬롯이면 실패 가능 | 물건·슬롯 수, 짝 데이터 | JUN_13 바나나, JUN_15 신전 문, JUN_17 지도, LAB_04 유물, LAB_14 진열장 |
| 회전 | 손잡이를 원을 그리며 돌려 게이지 채우기. 멈추면 되돌아갈 수 있음 | 필요 회전량, 되감기 속도 | DES_10 레버, JUN_12 도르래, FOR_19 발전기, FOR_14 냄비(속도 유지형) |
| 문지르기·스와이프 게이지 | 좌우로 문질러 게이지 채우기 (닦기, 털기, 톱질, 부채질) | 필요 이동량, 단계 수 | DES_09 관, JUN_11 이끼, FOR_08 톱질, LAB_15 칠판 |
| 연타 게이지 | 탭 횟수로 게이지 채우기. 상한을 넘으면 실패하는 변형 있음 | 필요 횟수, 허용 오차 | DES_02 문, JUN_16 코코넛, CAV_13 벽, LAB_19 타자기 |
| 순서 누르기 | 화면에 보이는 순서대로 대상 탭. 틀리면 실패 | 대상 수, 순서 데이터 | DES_06 버튼, JUN_05 앵무새, PRE_05 손잡이, LAB_02 샘플 |
| 틀린그림 | 두 그림 비교 후 다른 곳 탭 | 정답 위치(영역) 데이터 | DES_04 벽화, CAV_05 통로, LAB_09 DNA |
| 카메라 촬영 (덕 헌트) | 카메라 프레임을 드래그해 대상에 맞추고 촬영 버튼으로 찍기 | 찍을 대상 수(기본 3) | JUN_20, PRE_07, FOR_07 |
| 손전등 비추기 | 어둠 마스크 위에서 빛을 드래그해 숨은 대상 찾기 | 대상 수, 빛 반경 | CAV_03 출구, CAV_06 보물상자, FOR_12 부엉이 |
| 장애물 피하기 | 캐릭터를 움직여 장애물을 피함 (버티기형 많음) | 장애물 속도·수 | DES_01 함정, JUN_03 피라냐, CAV_09 돌, CAV_10 종유석 |

정확한 대응은 각 미니게임의 `mechanics`와 `how_to_play`를 보고 판단한다. 위 표에 없는 미니게임(예: PRE_14 청기백기, CAV_18 광차 갈림길)은 템플릿을 조합하거나 개별로 만든다.

## 구현 공통 사항

- 대상 위치와 정답은 매번 랜덤으로 배치해서 외워서 깨는 것을 막는다.
- 성공·실패 리액션(표정, 이펙트)은 아트 담당이다. 코드는 성공/실패 시점에 스프라이트를 바꿔 끼울 자리만 둔다.
- 4초 안에 끝나는 분량이 기준이다. 실기기 플레이테스트 후 기획자가 수치를 조정한다.
