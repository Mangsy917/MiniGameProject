## 플레이 방법

화면 전체를 덮은 낙엽을 빗자루로 스와이프해서 바깥으로 쓸어내라.

## 성공 / 실패

- **성공**: 낙엽을 95% 이상 쓸어내면 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 낙엽 수 | 약 90 | 화면 전체를 덮음 |
| 빗자루 범위 (`Broom Radius`) | 110 | - |
| 성공 비율 (`Clear Ratio`) | 95% | - |

거리와 속도는 놀이 영역(800 × 500) 단위다.
