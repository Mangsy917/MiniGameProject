## 플레이 방법

통통 튀며 움직이는 과일들을 보고 지정된 과일의 개수를 숫자 버튼 3개 중에서 골라라.

## 성공 / 실패

- **성공**: 지정된 과일의 개수를 맞히면 성공.
- **실패**: 틀린 숫자를 고르면 실패. 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 과일 종류 | 3 (바나나·두리안·파인애플) | - |
| 화면의 과일 총 수 | 6~9 | 랜덤 |
| 지정 과일 수 | 2~4 | 랜덤 |
| 좌우 속도 (`Move Speed`) | 260 | 과일마다 0.7~1.2배 |
| 중력 (`Gravity`) | 1600 | 클수록 빠르게 튐 |
| 빨라지는 정도 (`Speed Up Per Second`) | 0.5 | 제한시간이 5초보다 1초 짧아질 때마다 +50% (4.5초 1.25배, 4초 1.5배) |
| 답 입력 | 숫자 버튼 3개 | 정답을 포함한 연속된 숫자 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
