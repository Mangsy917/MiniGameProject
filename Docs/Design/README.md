`{테마 코드}_{번호}` — 번호는 시트 '전체 미니게임' 탭의 테마 안 순서(01~20). 우선제작·후순위 탭으로 나눠도 ID는 전체 탭 기준이다.

## 문서 갱신 방법

우선제작 30개는 2026-11-25에 유니티 구현 기준으로 고쳤고 구글 시트의 우선제작·전체 탭에도 반영했다. 조정 수치와 구현 메모는 시트에 없으므로, 시트로 문서를 다시 만들 때 `Priority/*.md`의 수치가 사라지지 않게 주의한다.

구글 시트를 고친 뒤 이 폴더의 `minigames.json`, `minigames.csv`, `MiniGames/*.md`, `Priority/*.md`를 다시 만든다. ID는 시트의 행 순서로 매겨지므로, **전체 탭에서 행 순서를 바꾸면 ID가 바뀐다.** 이미 구현된 미니게임이 있으면 행 순서는 바꾸지 않는다.
