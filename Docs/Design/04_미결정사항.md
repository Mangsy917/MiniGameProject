# 미결정 사항

기획자가 정할 때까지 코드에서 임의로 정하지 않는다. 구현에 꼭 필요하면 질문한다.

## 범위

- [ ] 8주 프로토타입에 넣을 미니게임 12종 (Must 8 + Should 4)
- [ ] 기다리거나 끝까지 버티는 유형(버티기 15개 등)을 유지할지 교체할지

## 제작 환경

- [ ] 화면 방향: 세로 / 가로 (제안: 세로)
- [ ] 대상 OS (제안: 안드로이드 우선)
- [ ] 아트 스타일, 기준 해상도

## 시트에서 고칠 것

- [ ] PRE_03: 이름 칸에 에셋 목록이 들어가 있음 ("암모나이트 화석(묻힘/발굴/부서짐), 곡괭이")
- [ ] JUN_04: 이름은 코코넛, 설명과 에셋은 바나나
- [ ] JUN_07: 플레이 방식 표기 "B 좌우 터치" → "B 좌우 회피"

## 결정됨 (2026-11-20)

- [x] 특수 라운드 등장 간격: 10라운드마다 (10, 20, 30, …)
- [x] 특수 라운드 형태: 전용 미니게임 없음
- [x] 체력회복 찬스 실패 시: 목숨 −1 (일반 라운드와 같음)
- [x] 스테이지 진행: 연구소를 제외한 5개 스테이지는 처음부터 열려 있고 플레이어가 선택, 5개 모두 클리어 시 연구소 해금
- [x] 미니게임 선택: 테마 안에서 랜덤, 직전에 나온 미니게임 제외
- [x] 지시문: 목숨 표시(대기 화면) 이후 미니게임 화면 안에 계속 표시, 별도 표시 시간 없음 (만져라 메이드 인 와리오 스타일)
- [x] 점수: 클리어한 라운드(미니게임) 수, 무한 모드에서만 표시
- [x] 특수 라운드 순서: 9라운드 종료 → 10라운드 시작과 체력회복 찬스 연출 → 10라운드 (클리어 +1, 실패 −1) → 스피드업 연출 → 11라운드부터 −0.5초 (20·30·… 라운드도 같음)
- [x] 제한시간 하한: 일단 4.0초 고정 (나중에 낮아질 수 있음). 하한 도달 후 스피드업 연출 생략
- [x] 스테이지 클리어: 20라운드를 마치면 클리어. 마지막 라운드에서 실패해도 목숨이 남아 있으면 클리어로 인정
- [x] 무한 모드: 유지 (연구소 클리어 시 해금), 120개 전체 랜덤
