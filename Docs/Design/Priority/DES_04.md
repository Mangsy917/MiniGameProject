## 플레이 방법 (시트 원문)

원본 벽화와 비교해서 틀린 부분 3곳을 모두 찾아 탭해라.

## 성공 / 실패

- **성공**: 틀린 부분을 모두 찾아 탭하면 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (인스펙터에 노출, 아래 값이 기본값)

| 수치 | 기본값 | 설명 |
|---|---|---|
| 벽화 세트 수 | 4 | 매번 1세트 랜덤 |
| 틀린 부분 수 | 1 | 에셋 기준 '각 1곳'. 플레이 방법 문구는 '3곳'이라 확인 필요 |
| 오답 탭 | 무시 | 틀린 곳이 아닌 곳을 탭해도 실패 아님 (제안) |

## 확인 필요 (기획자 답변 전까지 아래 가정으로 구현)

- [ ] 플레이 방법은 '틀린 부분 3곳', 필요 에셋은 '틀린 부분 각 1곳'으로 서로 다릅니다. 수치는 1로 두고 인스펙터에서 바꿀 수 있게 함.
- [ ] 틀린 곳이 아닌 곳을 탭했을 때 실패로 할지 (현재: 무시).
