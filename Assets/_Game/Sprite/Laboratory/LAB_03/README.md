# LAB_03 보안 패턴을 입력해라 — 에셋 자리

아트팀이 이 폴더에 아래 파일을 넣는다. 파일이 없는 동안 코드는 `Assets/_Game/Art/Placeholder/`의 임시 이미지를 쓴다.

- 지시문: 입력해라!
- 플레이 방법: 숫자가 위에 4개가 랜덤해서 생성되고, 거기에 맞는 비밀번호를 입력하면 된다.

| 파일 | 에셋 | 상태·설명 |
|---|---|---|
| `LAB_03_01.png` | 3×3 보안 패드 | - |
| `LAB_03_02.png` | 실험실 문 | - |

상태가 여러 개면(예: 꺼짐/켜짐) 적힌 순서대로 `_1`, `_2`를 붙인다. 예: `LAB_03_01_1.png`, `LAB_03_01_2.png`
