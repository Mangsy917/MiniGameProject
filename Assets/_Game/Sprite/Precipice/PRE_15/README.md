# PRE_15 흔들다리를 건너라 — 에셋 자리 (우선제작)

아트팀이 이 폴더에 아래 파일을 넣는다. 파일이 없는 동안 코드는 임시 이미지를 쓴다.

- 지시문: 건너라!
- 플레이 방법: 캐릭터의 시야(1인칭)에서 앞에 놓인 판자 10개 중 멀쩡한 판자만 순서대로 탭해서 앞으로 건너라. 부서진 판자를 밟으면 떨어져 실패. 부서진 판자는 2개 연속으로 나오지 않는다.
- 구현 문서: `Docs/Design/Priority/PRE_15.md`
