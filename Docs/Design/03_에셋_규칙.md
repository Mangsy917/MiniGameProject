# 에셋 규칙

이미지는 아트팀이 만든다. 코드는 이미지가 들어갈 자리(스프라이트 필드)만 만들고, 그림이 없는 동안 임시 이미지를 쓴다.

## 폴더

```
Assets/_Game/Sprite/
  Desert/      DES_01 ~ DES_20/
  Jungle/      JUN_01 ~ JUN_20/
  Cave/        CAV_01 ~ CAV_20/
  Precipice/   PRE_01 ~ PRE_20/
  Forest/      FOR_01 ~ FOR_20/
  Laboratory/  LAB_01 ~ LAB_20/
  Common/      (공용 에셋, 아래 참고)
```

미니게임 폴더마다 `README.md`가 있고, 필요한 파일 목록이 적혀 있다. 테마 폴더 바로 아래에 있는 기존 파일(`Menu.png` 등)은 그대로 둔다.

## 파일 이름

- 기본: `{ID}_{슬롯번호}.png` — 예: `JUN_10_01.png` (파인애플)
- 상태가 여러 개인 에셋: 명세에 적힌 상태 순서대로 `_1`, `_2`를 붙인다.
  - 예: `FOR_16_02`가 "모닥불(단계별 불 크기)"이면 `FOR_16_02_1.png`, `FOR_16_02_2.png`, …
  - 예: `CAV_15_01`이 "횃불(꺼짐/켜짐)"이면 `CAV_15_01_1.png`(꺼짐), `CAV_15_01_2.png`(켜짐)
- 애니메이션 프레임도 같은 방식으로 번호를 붙인다.
- 슬롯 번호와 에셋 이름의 대응은 각 폴더의 `README.md`, `MiniGames/{테마}.md`, `minigames.json`의 `asset_slots`에 있다.

## 임시 이미지

그림이 없을 때는 `Assets/_Game/Art/Placeholder/`의 `Circle.png`, `Square.png`, `GridTile.png`를 색과 크기만 바꿔 쓴다. 대상끼리 구분되도록 색을 다르게 하고, 정답·오답 구분이 필요한 경우 색으로 표시한다.

## 공용 에셋 (Common 폴더 권장)

여러 미니게임이 같은 그림을 쓸 수 있는 것들. 아트팀이 한 번만 만들고 같이 쓴다.

| 공용 에셋 | 쓰는 미니게임 |
|---|---|
| 카메라 프레임, 촬영 버튼, 플래시 이펙트 | JUN_20, PRE_07, FOR_07 |
| 횃불(꺼짐/켜짐), 어둠 마스크, 손전등 빛 | CAV_02~06, CAV_15, FOR_12 |
| 레일, 광차 | CAV_07, CAV_18 |
| 원숭이·앵무새·나무늘보 등 동물 캐릭터 | 정글 미니게임 여러 개 |
| 반짝임·성공 이펙트, 실패 이펙트 | 전체 |

## 크기와 해상도

화면 방향(세로/가로)이 미정이라 아직 정하지 않았다. 정해지면 이 문서에 기준 해상도와 대상 최소 크기(손가락으로 누르기 쉬운 크기)를 추가한다.
