## 플레이 방법

버튼 3개에서 나온 선이 얽혀 있다. 선을 눈으로 따라가서 가운데 기계와 이어진 버튼 하나를 찾아 탭해라. 다른 버튼을 누르면 실패.

## 성공 / 실패

- **성공**: 기계와 이어진 버튼을 탭하면 성공.
- **실패**: 다른 버튼을 탭하면 스파크와 함께 실패. 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 버튼 수 | 3 | - |
| 선 패턴 (`Patterns`) | 3종 | 매번 랜덤. 정답 버튼: 1번 오른쪽, 2번 가운데, 3번 왼쪽 |
| 좌우 반전 (`Random Mirror`) | 랜덤 | 경우의 수 2배 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
