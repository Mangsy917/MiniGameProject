## 플레이 방법

벽에 박힌 다이아를 탭해서 정해진 횟수(랜덤, ±1 허용)만큼 두드려 꺼내라. 횟수를 넘기면 다이아가 부서져 실패.

## 성공 / 실패

- **성공**: 다이아가 드러난 뒤 0.5초 멈추면 성공.
- **실패**: 너무 많이 두드리면 부서져 실패. 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 목표 횟수 N (`Min/Max Target`) | 6~12 | 매번 랜덤 |
| 허용 범위 (`Tolerance`) | N-1 ~ N+1 | N-1번째부터 드러나고 N+2번째 탭에서 부서짐 |
| 멈춤 판정 (`Stop Time`) | 0.5초 동안 탭 없음 | - |

거리와 속도는 놀이 영역(800 × 500) 단위다.
