## 플레이 방법 (시트 원문)

랜덤한 위치에서 나오는 전갈을 탭해서 모두 잡아라. (총 5마리)

## 성공 / 실패

- **성공**: 전갈 5마리를 모두 탭하면 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

| 수치 | 기본값 | 설명 |
|---|---|---|
| 전갈 수 | 5 | 우선제작 시트 기준 (전체 시트는 10) |
| 이동 속도 | 느림 | 화면 안을 천천히 돌아다님 |
| 등장 방식 | 시작 시 모두 등장 | 방향: 처음부터 모두 화면에 있음 |
