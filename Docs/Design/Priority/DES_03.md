## 플레이 방법

랜덤한 위치에서 돌아다니는 전갈을 탭해서 모두 잡아라. (총 5마리) 제한시간이 짧을수록 전갈이 빨라진다.

## 성공 / 실패

- **성공**: 전갈 5마리를 모두 탭하면 성공.
- **실패**: 시간 초과.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 전갈 수 (`Target Count`) | 5 | - |
| 이동 속도 (`Move Speed`) | 320 | - |
| 빨라지는 정도 (`Speed Up Per Second`) | 0.5 | 제한시간이 5초보다 1초 짧아질 때마다 +50% (4.5초 1.25배, 4초 1.5배) |
| 등장 방식 | 시작 시 모두 등장 | 벽에 튕기며 움직임 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
