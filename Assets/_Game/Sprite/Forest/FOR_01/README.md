# FOR_01 텐트의 못을 박아라 — 에셋 자리 (우선제작)

아트팀이 이 폴더에 아래 파일을 넣는다. 파일이 없는 동안 코드는 임시 이미지를 쓴다.

- 지시문: 못을 박아라!
- 플레이 방법: 비스듬히 내려다본 화면 가운데의 못을 연타해서 박아라. 한 개를 다 박으면 옆으로 넘어가 다음 못이 나온다. 못은 총 4개이고, 다음 못으로 완전히 넘어가야 박을 수 있다.
- 구현 문서: `Docs/Design/Priority/FOR_01.md`

| 파일 | 에셋 | 상태·설명 |
|---|---|---|
| `FOR_01_01.png` | 지주못 | 박힘 단계 1/2/3/4. 세로로 그림 (아래쪽부터 땅에 가려짐) |
| `FOR_01_02.png` | 망치 | 오른쪽 아래에 손잡이 |

상태가 여러 개면 적힌 순서대로 `_1`, `_2`를 붙인다. 예: `FOR_01_01_1.png`, `FOR_01_01_2.png`
넣은 뒤 유니티 메뉴 **MiniGame > 스프라이트 자동 연결**을 누른다.
