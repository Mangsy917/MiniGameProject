## 플레이 방법 (시트 원문)

버튼 3개에서 나온 선이 얽혀 있다. 선을 눈으로 따라가서 기계와 이어진 버튼 하나를 찾아 탭해라. 다른 버튼을 누르면 실패.

## 성공 / 실패

- **성공**: 기계와 이어진 버튼을 탭하면 성공.
- **실패**: 다른 버튼을 탭하면 스파크와 함께 실패.
- 제한시간은 `StageFlowController`가 잰다 (5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (인스펙터에 노출, 아래 값이 기본값)

| 수치 | 기본값 | 설명 |
|---|---|---|
| 버튼 수 | 3 | - |
| 선 패턴 | 3~5장 | 아트가 그린 이미지, 패턴마다 정답 버튼 데이터 |
| 좌우 반전 | 랜덤 | 경우의 수 2배 |
