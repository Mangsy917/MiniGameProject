## 플레이 방법 (시트 원문)

부싯돌을 적당한 속도로 드래그해서 장작에 불을 붙여라. 너무 빨리 긁으면 부싯돌이 부서져 실패. (참고: 어몽어스 카드 긁기)

## 성공 / 실패

- **성공**: 부싯돌을 적당한 속도로 정해진 횟수 긁으면 불이 붙어 성공.
- **실패**: 너무 빨리 긁으면 부싯돌이 부서져 실패.
- 제한시간은 `StageFlowController`가 잰다 (5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (인스펙터에 노출, 아래 값이 기본값)

| 수치 | 기본값 | 설명 |
|---|---|---|
| 필요 긁기 횟수 | 3 | - |
| 최대 속도 | 화면 너비/0.15초 | 이보다 빠르면 실패 |
| 최소 길이 | 부싯돌 길이의 70% | 짧게 긁으면 횟수에 넣지 않음 |
