## 확인 필요 모음

기획자 답변 전까지 각 문서에 적힌 가정으로 구현한다.

- **DES_01 피라미드의 함정을 피해라**: 끝나는 조건이 '버티기'인데 플레이 방법은 '출구까지 가라'입니다. 출구에 닿으면 바로 성공으로 처리하고, 시간이 끝날 때까지 출구에 못 가도 찔리지 않았으면 성공(버티기)으로 둘지 확인 필요. 이 문서는 둘 다 성공으로 적음 (`SucceedOnTimeUp = true` + 출구 도착 시 `Finish(true)`).
- **DES_04 벽화의 틀린 부분을 찾아라**: 플레이 방법은 '틀린 부분 3곳', 필요 에셋은 '틀린 부분 각 1곳'으로 서로 다릅니다. 수치는 1로 두고 인스펙터에서 바꿀 수 있게 함.
- **DES_04 벽화의 틀린 부분을 찾아라**: 틀린 곳이 아닌 곳을 탭했을 때 실패로 할지 (현재: 무시).
- **DES_15 박쥐를 잡아라**: 박쥐 수가 시트에 없습니다 (현재 1마리).
- **DES_15 박쥐를 잡아라**: 같은 미니게임이 연구소 '탈출한 박쥐를 잡아라'(LAB_11, 후순위)에도 있습니다.
- **JUN_04 떨어지는 코코넛을 잡아라**: 시트 이름은 '떨어지는 코코넛을 잡아라'인데 플레이 방법·에셋은 바나나입니다. 이 문서는 바나나로 구현.
- **JUN_09 과일의 개수를 맞춰라**: 답을 입력하는 방식이 시트에 없습니다. 숫자 버튼 3개 중 고르기로 적음.
- **JUN_09 과일의 개수를 맞춰라**: 시트 지시문은 '(과일 이름)에 수는?'인데 맞춤법상 '의 수는?'으로 적음.
- **CAV_08 화석을 발굴해라**: '±1 허용'의 판정 방식이 시트에 없습니다. PRE_03과 같은 방식으로 적음.
- **PRE_03 암모나이트 화석을 발굴해라**: 시트 이름 칸에 에셋 목록이 들어가 있습니다. 이름은 '암모나이트 화석을 발굴해라'로 적음.
- **PRE_03 암모나이트 화석을 발굴해라**: '±1 허용'의 판정 방식이 시트에 없습니다. 목표 횟수 N-1~N+1에서 0.5초 멈추면 성공, N+2번째 탭에서 부서져 실패로 적음. 동굴 CAV_08과 같은 로직.
