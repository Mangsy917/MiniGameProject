## 플레이 방법

좌우로 스와이프해서 화면 위쪽 밖에서 굴러오는 돌을 끝까지 피해라. 부딪히면 실패. 제한시간이 짧을수록 돌이 빨라진다.

## 성공 / 실패

- **성공**: 시간이 끝날 때까지 돌에 맞지 않으면 성공 (버티기).
- **실패**: 돌에 닿으면 즉시 실패.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 굴러오는 돌 수 | 3 | 화면 밖으로 나가면 위쪽 밖에서 다시 나옴 |
| 돌 속도 (`Rock Speed`) | 620 | - |
| 빨라지는 정도 (`Speed Up Per Second`) | 0.5 | 제한시간이 5초보다 1초 짧아질 때마다 +50% (4.5초 1.25배, 4초 1.5배) |
| 출발 간격 (`Rock Interval`) | 0.5초 | - |
| 캐릭터 쪽으로 올 확률 (`Aim Ratio`) | 50% | 나머지는 랜덤 위치 |
| 캐릭터 속도 | 900 | 스와이프한 만큼 좌우 이동 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
