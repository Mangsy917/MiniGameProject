## 플레이 방법

바구니를 좌우로 드래그해서 랜덤하게 떨어지는 바나나를 모두 받아라. 하나라도 놓치면 실패. 다 받으면 바로 성공.

## 성공 / 실패

- **성공**: 바나나를 모두 받으면 즉시 성공.
- **실패**: 바나나를 놓치면 즉시 실패.
- 제한시간은 `StageFlowController`가 잰다 (기획: 5.0 / 4.5 / 4.0초). 4.0초 안에 끝낼 수 있는 분량이어야 한다.

## 조정 수치 (프리팹 인스펙터, 현재 값)

| 수치 | 현재 값 | 설명 |
|---|---|---|
| 바나나 수 | 4 | - |
| 낙하 속도 (`Fall Speed`) | 520 | - |
| 빨라지는 정도 (`Speed Up Per Second`) | 0.5 | 제한시간이 5초보다 1초 짧아질 때마다 +50% (4.5초 1.25배, 4초 1.5배) |
| 떨어지는 시간 | 랜덤 | 최소 간격 0.35초 (`Min Drop Gap`) |
| 바구니 이동 | 좌우만 | 손가락 위치를 바로 따라감 |

거리와 속도는 놀이 영역(800 × 500) 단위다.
